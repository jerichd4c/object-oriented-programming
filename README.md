## About The Repository

This repository brings together the material covered in the **Object Oriented Programming** course at URU. Its purpose is to keep the final, working version of each project in one organized place.

Each project folder is self-contained and has its own README with setup instructions and implementation details.

## Getting Started

Each project has its own compile/run instructions — see its individual README linked in [Main Projects](#main-projects).

### Prerequisites

* Java JDK 11 or higher

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/jerichd4c/object-oriented-programming.git
   ```
2. Open the folder for the project you want to run.
3. Follow that project's own README.

## Repository Structure

These are the projects currently available in the repository:

* `office-space-proyect/`: a console application simulating an office layout as a matrix, with employee/boss assignment.
* `jframe-file-explorer/`: a Swing/JFrame desktop file explorer with text file reading, stats, and encryption.

<p align="right">(<a href="#readme-top">back to top</a>)</p>

## Main Projects

### [Office Space Project](office-space-proyect/README.md)
A Java console application that simulates and manages an office space represented as a matrix, with employees and a boss assigned to cubicles.
* **Features**: cubicle view, employee/boss assignment and removal, adjacent-cubicle lookup.
* **Documentation**: [Project README](office-space-proyect/README.md)

### [Jframe File Explorer](jframe-file-explorer/README.md)
A lightweight desktop file explorer built with Swing/JFrame, for browsing and managing `.txt` files.
* **Features**: open/read files, view statistics, conditional encryption.
* **Documentation**: [Project README](jframe-file-explorer/README.md)
